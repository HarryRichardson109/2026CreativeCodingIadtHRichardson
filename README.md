<p> This repository is a collection of sketches created in processing 4 as part of the IADT tertiary course.  

This readme will serve as a index of this small collection of code.  

If statements - basic if statements used to create interactivity from the user. sends a true or false signal to execute cold held within. Can be used in conjunction with else if to create a signal on false for a different part of code.

bubble sort - loops and arrays in order to sort groups of information. bubble sorts will swap parts of the array each update until no more swaps are needed.

Snowfall - loop and array used to create graphics such as snow falling or bubbles rising.  The array is used to instantiate the moving bubbles and the loop keeps resetting them once they reach the top.

Rooms_codeProj - all previous subjects covered used to solve a math puzzle in which there are 100 rooms.  

sound - imported sound to respond to audio input.  

Image - imported and loaded an image onto the canvas.  

MichaelCodingFinal - Final project for first semester which combines every previous aspect on this list.
